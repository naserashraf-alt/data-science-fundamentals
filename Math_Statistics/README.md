# 📐 Math & Statistics Reference Deck — Eng. Nasser

A modern, high-performance, and interactive **Math & Statistics Reference Deck** created for students, engineers, and developers. Built with an Executive Floating Navigation Deck, live search engine, responsive dark/light modes, and interactive SVG diagrams.

---

## 🌟 Key Features

- **🚀 Executive Top Floating Deck**: Fixed glassmorphic navigation header with live search bar and smooth navigation pills.
- **🔍 Instant Live Search**: Filter formulas, definitions, and topics in real-time.
- **🎨 Dark & Light Modes**: Seamless 1-click theme switcher with custom CSS variables.
- **📊 Interactive SVG Diagrams**: Visual illustrations for Boxplots, Histograms, Normal Distribution (68-95-99.7 Rule), Skewness, and Scatter Plots with hover tooltips.
- **📋 1-Click Code Copy**: Copy mathematical formulas and snippets instantly.
- **📱 Fully Responsive**: Optimized for desktops, tablets, and mobile devices.

## 📥 How to Download and Open from GitHub

### 🔹 Option 1: Download as ZIP (Easiest — No Git required)

1. Go to the main page of this GitHub repository.
2. Click the green **`Code`** button located at the top right of the file list.
3. Select **`Download ZIP`** from the dropdown menu.
4. Once downloaded, extract (unzip) the file to any folder on your computer.
5. Double-click **`index.html`** to open it directly in your browser (Google Chrome, Microsoft Edge, Firefox, Safari, etc.).

---

### 🔹 Option 2: Clone using Git (For Developers)

1. Open your terminal or command prompt (Terminal, Git Bash, or PowerShell).
2. Run the following command to clone the repository:
   ```bash
   git clone https://github.com/your-username/repository-name.git
   ```
3. Navigate into the project folder:
   ```bash
   cd repository-name
   ```
4. Open `index.html` in your browser or run it using a local web server:
   - **VS Code**: Right-click `index.html` → **Open with Live Server**.
   - **Python**: Run `python -m http.server 8000` and open `http://localhost:8000`.
