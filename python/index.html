01

Intro to Python

Python is a high-level, interpreted language known for clean, readable syntax. There's no compiling step — you write code and run it directly. Indentation (not curly braces) defines blocks, which is why formatting matters in Python.

your first program
print("Hello, World!")
print("Learning Python is fun")
comments & indentation
# This is a single-line comment

"""
This is a
multi-line comment
"""

if True:
    print("Indented block")  # 4 spaces = one block
Python files end in .py. Run one from the terminal with python filename.py (or python3 on Mac/Linux).

Variables & Data Types

A variable is a name that points to a value in memory. Python is dynamically typed — you don't declare a type, Python figures it out from the value you assign.

declaring variables
name = "Ahmed"        # str
age = 21               # int
gpa = 3.75             # float
is_student = True      # bool
skills = ["Python", "SQL"]  # list

x = y = z = 0          # multiple assignment
a, b = 1, 2            # tuple unpacking

print(type(age))       #
core data types
TypeExample
int10, -3, 0
float3.14, -0.5
str"hello"
boolTrue, False
NoneTypeNone
Naming rule: variable names can't start with a number, can't contain spaces, and are case-sensitive — age and Age are different variables.

String Methods & f-strings

Strings come with a huge set of built-in methods for cleaning, splitting, and rebuilding text — and f-strings are the modern, readable way to plug values straight into a string.

f"{var}" .split() .join() .strip() .replace()
f-strings — inserting values
name = "Sara"
age = 21

print(f"{name} is {age} years old")
# Sara is 21 years old

# expressions work too
print(f"Next year she'll be {age + 1}")

# formatting numbers inline
price = 19.5
print(f"${price:.2f}")   # $19.50
.format() — the older style
name = "Omar"
age = 25

print("{} is {} years old".format(name, age))
# Omar is 25 years old

# with positional/named placeholders
print("{0} scored {1}%".format(name, 90))
print("{n} scored {s}%".format(n=name, s=90))
.split() — string to list
sentence = "the quick brown fox"
words = sentence.split()          # splits on whitespace
print(words)   # ['the', 'quick', 'brown', 'fox']

csv_line = "Sara,21,Cairo"
fields = csv_line.split(",")      # split on a custom separator
print(fields)   # ['Sara', '21', 'Cairo']
.join() — list to string
words = ["the", "quick", "brown", "fox"]

sentence = " ".join(words)
print(sentence)   # the quick brown fox

fields = ["Sara", "21", "Cairo"]
csv_line = ",".join(fields)
print(csv_line)   # Sara,21,Cairo
.strip() — trimming whitespace
text = "   Hello World!   "

print(text.strip())     # "Hello World!" (both sides)
print(text.lstrip())    # "Hello World!   " (left only)
print(text.rstrip())    # "   Hello World!" (right only)

# also removes custom characters
print("***Hi***".strip("*"))   # "Hi"
.replace() — swapping text
text = "I like cats"
new_text = text.replace("cats", "dogs")
print(new_text)   # I like dogs

# case-changing methods are handy too
print("Hello".upper())     # HELLO
print("Hello".lower())     # hello
print("hello world".title())  # Hello World
MethodPurposeExample
.split(sep)String → list, cut at each separator"a,b".split(",") → ['a','b']
.join(list)List → string, glued with this separator",".join(['a','b']) → "a,b"
.strip()Remove leading/trailing whitespace" hi ".strip() → "hi"
.replace(old,new)Swap all occurrences of a substring"hi".replace("h","H") → "Hi"
f"{x}"Insert a variable/expression directly into a stringf"{2+2}" → "4"
Prefer f-strings over .format() or + concatenation in modern Python — they're faster, more readable, and let you run expressions and formatting right inside the braces.

Type Casting

Type casting means converting a value from one type to another using built-in functions: int(), float(), str(), and bool().

converting types
age_text = "21"
age_num = int(age_text)      # "21" -> 21

price = float("9.99")        # "9.99" -> 9.99
count = str(100)              # 100 -> "100"

print(int("21") + 4)          # 25
print(str(21) + " years")     # "21 years"
watch out for this
int("21.5")     # ❌ ValueError
int(float("21.5"))   # ✅ 21 (truncates)

bool(0)         # False
bool("")        # False
bool("0")       # True  (non-empty string!)
bool([])        # False

Conditional Statements

Conditionals let your program make decisions using if, elif, and else. Only the first true condition's block runs.

if / elif / else
age = 20

if age < 13:
    print("Child")
elif age < 20:
    print("Teenager")
else:
    print("Adult")
# Output: Adult
shorthand & nesting
# Ternary (one-line if/else)
status = "Adult" if age >= 18 else "Minor"

# Nested conditions
if age >= 18:
    if age >= 65:
        print("Senior")
    else:
        print("Adult")
Anything other than 0, None, empty string/list is treated as True — this is called "truthy" evaluation.

for / while Loops

Loops repeat code. Use for when iterating over a known sequence, and while when repeating until a condition becomes false.

for loop
for i in range(5):
    print(i)          # 0 1 2 3 4

fruits = ["apple", "mango", "kiwi"]
for fruit in fruits:
    print(fruit)

for i in range(2, 10, 2):
    print(i)          # 2 4 6 8
while loop
count = 0
while count < 5:
    print(count)
    count += 1

# while + else
n = 0
while n < 3:
    print(n)
    n += 1
else:
    print("Loop finished!")

break / continue / pass

These keywords change how a loop behaves mid-execution.

KeywordEffect
breakExits the loop immediately
continueSkips to the next iteration
passDoes nothing — a placeholder
break & continue
for i in range(10):
    if i == 5:
        break          # stop the loop
    print(i)           # 0 1 2 3 4

for i in range(6):
    if i % 2 == 0:
        continue       # skip even numbers
    print(i)           # 1 3 5
pass
for i in range(5):
    if i == 3:
        pass            # do nothing, keep going
    print(i)

def todo_function():
    pass   # placeholder so code doesn't break

Lists, Tuples, Dictionaries, Sets

Python's four built-in collection types — each with a different job: ordered & changeable, ordered & fixed, key-value pairs, and unique unordered items.

lists
fruits = ["apple", "mango", "kiwi"]
fruits.append("banana")
fruits.remove("kiwi")
fruits[0] = "orange"
print(fruits[0])       # orange
print(fruits[-1])      # banana
print(len(fruits))     # 4
tuples
point = (10, 20)
x, y = point            # unpacking
print(point[0])         # 10

# point[0] = 5  -> ❌ TypeError, tuples are immutable
dictionaries
student = {
    "name": "Sara",
    "age": 22,
    "major": "CS"
}
print(student["name"])     # Sara
student["age"] = 23        # update
student["gpa"] = 3.9       # add new key

for key, value in student.items():
    print(key, "->", value)
sets
nums = {1, 2, 3, 3, 2}
print(nums)            # {1, 2, 3} - duplicates gone

a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)   # union {1,2,3,4}
print(a & b)   # intersection {2,3}
print(a - b)   # difference {1}
StructureOrdered?Mutable?Duplicates?Syntax
ListYesYesAllowed[1, 2, 3]
TupleYesNoAllowed(1, 2, 3)
DictionaryYes (3.7+)YesUnique keys only{"a": 1}
SetNoYesNever — auto-removed{1, 2, 3}

Functions & Scope

A function is a reusable block of code defined with def. Functions take in parameters, can send back a return value, and every variable inside one lives in its own scope.

Parameters Return Values Lambda Scope · LEGB
parameters
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Sara")                   # Hello, Sara!
greet("Sara", "Hi")              # Hi, Sara!
greet(name="Sara", greeting="Hey")  # keyword arg

# *args -> extra positional args as a tuple
# **kwargs -> extra keyword args as a dict
def add_all(*args, **kwargs):
    print(args, kwargs)

add_all(1, 2, 3, x=10)   # (1, 2, 3) {'x': 10}
return values
def square(n):
    return n * n

result = square(5)      # 25

def min_max(numbers):
    return min(numbers), max(numbers)   # returns a tuple

low, high = min_max([4, 1, 9, 3])
print(low, high)         # 1 9

def say_hi():
    print("hi")          # no return -> returns None
lambda functions
# lambda arguments: expression
square = lambda n: n * n
print(square(6))          # 36

add = lambda a, b: a + b
print(add(2, 3))          # 5

# common use: as a quick key/sort function
names = ["Ali", "Bo", "Zayn"]
names.sort(key=lambda n: len(n))
print(names)               # ['Bo', 'Ali', 'Zayn']
scope: local, enclosing, global, built-in
x = "global"              # Global scope

def outer():
    y = "enclosing"        # Enclosing scope
    def inner():
        z = "local"         # Local scope
        print(z, y, x)       # sees all three
        print(len)            # Built-in scope (len, print...)
    inner()

outer()

def change_global():
    global x
    x = "changed!"           # modifies the global x
ScopeMeaning
LocalNames created inside the current function
EnclosingNames in the scope of an outer (wrapping) function
GlobalNames defined at the top level of the module/file
Built-inNames Python provides automatically, like print, len
This lookup order is the LEGB rule — Python searches Local → Enclosing → Global → Built-in until it finds the name.

Error Handling

When code might fail, wrap it in try so Python doesn't crash the whole program. except catches the error, else runs only if nothing went wrong, and finally always runs — success or failure.

basic try / except
try:
    num = int(input("Enter a number: "))
    result = 10 / num
    print(result)
except ZeroDivisionError:
    print("You can't divide by zero!")
except ValueError:
    print("That's not a valid number.")
catching multiple errors together
try:
    data = {"age": "twenty"}
    age = int(data["age"]) + 1
except (ValueError, KeyError) as e:
    print(f"Something went wrong: {e}")

# generic catch-all
try:
    risky_action()
except Exception as e:
    print(f"Unexpected error: {e}")
else & finally
try:
    file = open("data.txt")
except FileNotFoundError:
    print("File not found.")
else:
    print("File opened successfully!")
    file.close()
finally:
    print("Done attempting to read the file.")
raising custom exceptions
def set_age(age):
    if age < 0:
        raise ValueError("Age can't be negative")
    return age

try:
    set_age(-5)
except ValueError as e:
    print(e)

The datetime Module

The built-in datetime module lets you work with dates and times: grabbing the current moment, pulling out individual pieces, formatting them into readable strings, parsing strings back into dates, and doing date math.

getting current date & time
import datetime

now = datetime.datetime.now()
print(now)          # 2026-01-15 19:30:45.123456

today = datetime.date.today()
print(today)        # 2026-01-15
formatting with strftime()
now = datetime.datetime.now()

print(now.strftime("%Y-%m-%d"))          # 2026-01-15
print(now.strftime("%d/%m/%Y"))          # 15/01/2026
print(now.strftime("%A, %B %d %Y"))      # Thursday, January 15 2026
print(now.strftime("%I:%M %p"))          # 07:30 PM

File Handling, CSV & JSON

Python reads and writes files with the built-in open() function, always best used inside a with block so the file closes automatically. The csv and json modules build on this to handle two of the most common data formats.

reading & writing files
with open("notes.txt", "r") as file:
    content = file.read()

with open("notes.txt", "w") as file:
    file.write("First line\n")

with open("notes.txt", "a") as file:
    file.write("Appended line\n")
JSON handling
import json

data = {"name": "Sara", "age": 21}

# Save to JSON file
with open("data.json", "w") as file:
    json.dump(data, file, indent=4)

# Load from JSON file
with open("data.json", "r") as file:
    loaded = json.load(file)

Searching, Sorting & Recursion

These are the foundational algorithms every programmer builds on: how to find a value in a list, how to order a list, and how to write a function that calls itself to break a problem into smaller versions of itself.

binary search
def binary_search(items, target):
    low, high = 0, len(items) - 1
    while low <= high:
        mid = (low + high) // 2
        if items[mid] == target:
            return mid
        elif items[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

print(binary_search([1, 2, 4, 8, 9, 15], 9))  # 4
recursion: factorial
def factorial(n):
    if n == 0:              # base case
        return 1
    return n * factorial(n - 1)

print(factorial(5))   # 120

Classes, Encapsulation & Abstraction

Object-Oriented Programming (OOP) organizes code around objects — bundles of data (attributes) and behavior (methods). A class is the blueprint; an object is one instance built from that blueprint.

defining a class
class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

    def show(self):
        print(f"{self.name}: {self.grade}")

s = Student("Sara", 95)
s.show()   # Sara: 95
private attributes (encapsulation)
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance   # private

    def get_balance(self):
        return self.__balance

acc = BankAccount("Sara", 100)
print(acc.get_balance())   # 100

Inheritance & Polymorphism

Inheritance lets a class reuse the attributes and methods of another class instead of rewriting them. Polymorphism lets different classes respond to the same method call in their own way.

super() & method overriding
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        print("Sound")

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
    def speak(self):
        print("Woof!")

d = Dog("Rex", "Lab")
d.speak()   # Woof!
polymorphism
class Cat:
    def speak(self): print("Meow!")
class Duck:
    def speak(self): print("Quack!")

for animal in [Cat(), Duck()]:
    animal.speak()

Lambda, map, filter & reduce

A lambda is a small, unnamed function written in a single line — useful when you need a quick throwaway function.

map & filter with lambda
nums = [1, 2, 3, 4, 5, 6]

squared = list(map(lambda n: n * n, nums))
evens = list(filter(lambda n: n % 2 == 0, nums))

print(squared)  # [1, 4, 9, 16, 25, 36]
print(evens)    # [2, 4, 6]
