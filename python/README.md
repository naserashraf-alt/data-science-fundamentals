## 📥 How to Download and Open from GitHub

### 🔹 Option 1: Download as ZIP (Easiest — No Git required)

1. Open the repository page on GitHub.
2. Click the green **`Code`** button at the top right of the file list.
3. Select **`Download ZIP`** from the menu.
4. Extract (unzip) the downloaded file to a folder on your PC.
5. Double-click **`index.html`** to open it immediately in any web browser (Chrome, Edge, Firefox, Brave, Safari).

---

### 🔹 Option 2: Clone using Git (For Developers)

1. Open your terminal / command prompt.
2. Clone the repository using Git:
   ```bash
   git clone https://github.com/your-username/repository-name.git
   ```
3. Enter the project folder:
   ```bash
   cd repository-name
   ```
4. Launch `index.html` in your favorite web browser or use a live server extension in VS Code.
